# Pocket Training

A responsive climbing training and performance tracking prototype inspired by the supplied Sandstone Day reference. It runs without a build step: open `index.html` in a browser or serve this directory with any static file server.

The prototype includes Dashboard, Planner, Workouts, Metrics, Goals, and Tests. Click the climber profile at the bottom of the sidebar to edit personal information and metrics; profile and app changes are saved in browser `localStorage`. Use the browser developer tools to clear the `pocket-training-v1` key and restore the sample cycle.
